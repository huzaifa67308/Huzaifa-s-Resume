# Huzaifa Humayon — Resume Website

Original responsive resume website for Web Engineering Assignment #1. Built with HTML, CSS and vanilla JavaScript.

## Features
- Scroll reveal animations (IntersectionObserver)
- Animated hover cards
- Scroll progress indicator
- Dark/light mode with saved preference
- Responsive mobile navigation
- Copy email interaction

## Publish with GitHub Pages
1. Create a public GitHub repository, e.g. `huzaifa-resume-website`.
2. Upload `index.html`, `style.css`, `script.js` into the repository root.
3. Open Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Copy the live site URL once deployed.

The academic projects and certifications sections are not populated because the supplied resume did not provide verified items. Add them if applicable.
